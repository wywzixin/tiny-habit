# Tiny Habits - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
**Tiny Habits（微习惯）**

### 1.2 产品定位
基于福格行为模型（Fogg Behavior Model）的习惯养成应用，通过科学的行为设计方法帮助用户建立持久的好习惯。

### 1.3 目标用户
**主要用户**：25-40岁都市白领
- 希望改善生活习惯但屡次失败
- 工作繁忙，时间碎片化
- 追求自我提升和生活品质

**用户痛点**：
- 目标太大，难以坚持
- 缺乏即时反馈
- 不知如何开始

**解决方案**：
- 微行为：30秒内完成
- 即时庆祝：动画+积分
- 锚点提示：连接现有习惯

### 1.4 核心价值主张
> "每一个微小的开始，都通向伟大的改变"

通过将大目标拆解为极小的微行为，绑定到日常已有的锚点行为上，配合即时庆祝反馈，让习惯养成变得简单可持续。

---

## 2. 福格行为模型

### 2.1 模型公式
```
B = MAP
行为(Behavior) = 动机(Motivation) × 能力(Ability) × 提示(Prompt)
```

### 2.2 模型在产品中的应用

| 模型要素 | 产品功能 | 设计目标 |
|---------|---------|---------|
| **Motivation（动机）** | 行动值积分、庆祝动画、成就系统、鼓励文案 | 提供持续的正向激励 |
| **Ability（能力）** | 微行为设计（极小化任务）、难度分级 | 降低行动门槛 |
| **Prompt（提示）** | 锚点系统、智能提醒、通知推送 | 在正确时机触发行为 |

### 2.3 配方公式
```
当 [锚点行为] 后，我会 [微行为]，然后 [庆祝方式]
```

示例：
- 当 **刷完牙** 后，我会 **用牙线清洁一颗牙**，然后 **对自己微笑**
- 当 **倒好咖啡** 后，我会 **做两次深呼吸**，然后 **心里说太棒了**

### 3.2 首页 (Home)

**功能描述：** 用户的微行为管理中心，展示所有已创建的微行为配方，支持快速打卡。

**数据说明：** 首页展示的是微行为（子级），每个微行为归属于一个父习惯。

| 功能点 | 描述 | 优先级 |
|-------|------|-------|
| 微行为列表 | 展示用户所有微行为，显示锚点和行为 | P0 |
| 打卡按钮 | 点击完成微行为打卡，触发庆祝反馈 | P0 |
| 行动值显示 | 顶部显示累计行动值 | P0 |
| 今日能量卡片 | 展示每日激励语，点击触发彩带动画 | P1 |
| 完成状态 | 已完成微行为显示划线样式 | P0 |
| 父习惯分组 | 可按父习惯分组显示微行为 | P1 |

**交互细节：**
- 打卡时触发触觉反馈（震动）
- 打卡后显示烟花动画 + 庆祝弹窗
- 庆祝弹窗显示对应的庆祝方式提醒
- 弹窗 3 秒后自动关闭

### 3.3 发现页 (Discover) - 配方库

**功能描述：** 微行为配方模板库，提供系统预设和用户分享的完整配方，用户可直接添加为打卡项。

**配方库来源：**
- 系统预设配方（官方精选）
- 用户公开分享的配方

| 功能点 | 描述 | 优先级 |
|-------|------|-------|
| 配方列表 | 展示所有微行为配方模板，卡片形式 | P0 |
| 分类筛选 | 推荐/健康/学习/生活/心理/社交 | P0 |
| 搜索功能 | 关键词搜索配方名称和描述 | P1 |
| 配方预览 | 显示完整配方：锚点→行为→庆祝 | P0 |
| 一键添加 | 直接添加为我的打卡配方 | P0 |
| 热度排序 | 按使用人数排序 | P1 |
| 分享配方 | 用户可将自己的配方分享到配方库 | P1 |

**配方卡片信息：**
- 配方图标和名称
- 完整配方预览（锚点→行为→庆祝）
- 分类标签
- 难度标签（简单/适中/挑战）
- 使用人数

**交互流程：**
```
浏览配方库 → 点击配方卡片 → 预览配方详情 → 点击"一键添加" → 选择归属习惯 → 完成
```

### 3.4 创建配方页 (Create)

**功能描述：** 核心页面，引导用户按福格模型创建微行为配方。

**数据层级：**
```
习惯（父级）── 通过习惯库选择或手动创建
  └── 微行为（子级）：锚点 + 行为 + 庆祝
```

**创建流程：**
```
选择/创建习惯 → 输入目标 → AI推荐微行为 → 选择锚点 → 庆祝方式 → 频率设置 → 确认
```

| 功能点 | 描述 | 优先级 |
|-------|------|-------|
| 习惯输入框 | 输入或选择父习惯名称 | P0 |
| 习惯库按钮 | 输入框右侧按钮，点击弹出习惯库 | P0 |
| 目标输入 | 输入微行为目标 | P0 |
| AI推荐微行为 | 推荐4个微行为选项 | P0 |
| 难度标签 | 简单/适中/挑战 | P1 |
| AI推荐锚点 | 推荐4个触发时机 | P0 |
| 庆祝方式 | 6种预设庆祝方式 | P0 |
| 频率设置 | 周一至周日选择 | P0 |
| 提醒设置 | 选择提醒时间 | P0 |
| 配方预览 | 底部实时预览完整配方 | P0 |

### 3.8 奖励系统 (Rewards)

**功能描述：** 用户可以设定个人奖励，用行动值兑换。

**核心流程：**
```
创建奖励 → 积累行动值 → 达标兑换 → 记录历史
```

| 功能点 | 描述 | 优先级 |
|-------|------|-------|
| 创建奖励 | 设置名称、图标、所需行动值 | P1 |
| 奖励列表 | 展示所有待兑换奖励 | P1 |
| 兑换功能 | 扣除行动值，标记已兑换 | P1 |
| 兑换历史 | 查看已兑换的奖励记录 | P2 |

**积分规则：**
- 每次打卡 +1 行动值
- 行动值分为：累计、可用、已兑换
- 兑换后从可用行动值中扣除

**约束规则：**
- 每个用户最多创建 50 个奖励
- 奖励成本最低 10 行动值
- 兑换后不可撤销

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|-----|------|
| 应用启动时间 | < 2s |
| 打卡响应时间 | < 500ms |
| 庆祝动画触发 | < 300ms |
| API 响应时间 | < 200ms |

### 4.2 稳定性要求

| 指标 | 要求 |
|-----|------|
| 崩溃率 | < 0.5% |
| ANR 率 | < 0.1% |

### 4.3 兼容性要求

| 平台 | 最低版本 |
|-----|---------|
| iOS | 15.0+ |
| Android | 10.0+ |

### 4.4 离线支持

- 支持离线打卡，联网后自动同步
- 本地缓存习惯数据
- 离线时显示缓存的统计数据

## 6. 不做什么（明确边界）

### 6.1 MVP 阶段不做

**社交功能**
- 不做好友系统
- 不做习惯分享
- 不做排行榜
- 理由：专注个人习惯养成

**付费功能**
- 不做会员订阅
- 不做内购
- 理由：MVP 验证产品价值

### 6.2 永远不做

**强制性功能**
- 不强制每天打卡
- 不惩罚断签
- 理由：正向激励
